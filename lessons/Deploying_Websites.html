CHAPTER 05 · DEPLOYMENT

Deploying Websites

Learn the basic path from a working local website to a public deployment.

What is deployment?

Deployment adalah proses menerbitkan aplikasi ke environment tempat pengguna dapat mengaksesnya. Pastikan versi lokal berjalan dan asset memiliki path yang benar sebelum deploy.

Static hosting

Website HTML, CSS, dan JavaScript sisi browser dapat dipublikasikan melalui static hosting. GitHub Pages adalah salah satu opsi untuk project statis.

Important: Static hosting tidak menjalankan PHP/Laravel backend secara langsung. Aplikasi yang membutuhkan server-side runtime dan database memerlukan layanan hosting yang mendukungnya.

Deployment checklist

  1. Periksa semua halaman dan link.
  2. Pastikan CSS, JavaScript, dan gambar ditemukan.
  3. Periksa case-sensitive file paths.
  4. Uji tampilan mobile dan desktop.
  5. Periksa console dan network errors.
  6. Uji URL publik setelah deployment.
