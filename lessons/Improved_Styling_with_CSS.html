Improved Styling with CSS

Build polished interfaces using color, typography, spacing, layout systems, and transitions.

Colors and backgrounds

.hero {
  color: #f8fafc;
  background-color: #172554;
  background-image: linear-gradient(135deg, #172554, #4c1d95);
}

Warna CSS dapat ditulis dengan nama, HEX, RGB, atau HSL. Pastikan kontras teks dan background cukup.

Typography

body {
  font-family: Arial, sans-serif;
  font-size: 16px;
  line-height: 1.6;
}
h1 {
  font-size: 2.5rem;
  font-weight: 700;
  letter-spacing: -0.03em;
}

Tipografi memengaruhi keterbacaan dan hierarki visual. Gunakan skala ukuran konsisten.

Spacing, borders, and shadows

.card {
  margin: 24px auto;
  padding: 24px;
  border: 1px solid #334155;
  border-radius: 14px;
  box-shadow: 0 12px 30px rgba(0, 0, 0, .18);
}

Margin adalah ruang luar; padding adalah ruang dalam. Border radius membulatkan sudut; box shadow memberi bayangan.

Flexbox

.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
  flex-wrap: wrap;
}

Flexbox adalah layout satu dimensi. justify-content mengatur main axis, align-items mengatur cross axis.

CSS Grid

.card-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1.25rem;
}

Grid cocok untuk layout dua dimensi yang mengatur baris dan kolom.

Transitions and hover states

.button {
  transition: transform 180ms ease, background 180ms ease;
}
.button:hover {
  transform: translateY(-2px);
  background: rebeccapurple;
}

Transition membuat perubahan style lebih halus. :hover berlaku ketika pointer berada di atas elemen.
