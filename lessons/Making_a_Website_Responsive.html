CHAPTER 07 · RESPONSIVE DESIGN

Making a Website Responsive

Make layouts adapt to different viewport sizes using flexible dimensions, media queries, and mobile-first design.

Responsive web design

Responsive design membuat layout beradaptasi terhadap lebar viewport sehingga konten tetap mudah dibaca dan digunakan.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

.container {
  width: min(100% - 2rem, 1100px);
  margin-inline: auto;
}
img { max-width: 100%; height: auto; }

Gunakan ukuran fleksibel dan hindari konten melebar melebihi viewport.

.cards { display: grid; grid-template-columns: repeat(3, 1fr); }
@media (max-width: 800px) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}
@media (max-width: 560px) {
  .cards { grid-template-columns: 1fr; }
}

Media query menerapkan aturan CSS berdasarkan kondisi seperti lebar viewport. Breakpoint dipilih berdasarkan kebutuhan konten.

.cards { display: grid; grid-template-columns: 1fr; }
@media (min-width: 700px) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 1000px) {
  .cards { grid-template-columns: repeat(3, 1fr); }
}

Mobile-first dimulai dari layout layar kecil, lalu menambah kolom atau fitur saat ruang layar bertambah.

Responsive testing checklist

  • Pastikan meta viewport tersedia.
  • Periksa horizontal scrolling yang tidak disengaja.
  • Uji navigasi dengan sentuhan dan keyboard.
  • Pastikan teks dan tombol mudah dibaca.
  • Uji beberapa lebar viewport melalui browser DevTools.
