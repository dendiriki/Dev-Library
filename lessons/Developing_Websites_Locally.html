CHAPTER 04 · LOCAL DEVELOPMENT

Developing Websites Locally

Set up a local project, preview it in a browser, and debug issues before publishing.

Local development workflow

  1. Buat folder project.
  2. Buka folder melalui VS Code.
  3. Buat file HTML, CSS, dan JavaScript.
  4. Jalankan dengan local development server.
  5. Periksa hasil melalui browser Developer Tools.
  6. Perbaiki error dan uji kembali.
my-website/
├── index.html
├── components/
│   ├── navbar.html
│   └── footer.html
├── assets/
│   ├── css/style.css
│   ├── js/app.js
│   └── images/
└── lessons/
    ├── Fundamentals_of_HTML.html
    └── Fundamentals_of_CSS.html

Pemisahan folder membantu project tetap teratur saat halaman dan asset bertambah.

CommandFunction

Debugging basics

Developer Tools membantu memeriksa DOM, CSS, network requests, dan JavaScript errors. Console menampilkan pesan error; Elements/Inspector membantu memeriksa struktur dan style.

Tip: Periksa nama file, line number, selector, dan path asset sebelum mengubah banyak kode.
