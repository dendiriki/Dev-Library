Fundamentals of CSS

Understand CSS rules, selectors, cascade, specificity, inheritance, and the box model.

What is CSS?

CSS (Cascading Style Sheets) mengatur presentasi visual dokumen HTML: warna, typography, spacing, border, dan layout.

Remember: HTML = structure and meaning. CSS = presentation and layout.

CSS syntax

Aturan CSS terdiri dari selector dan declaration block. Declaration berisi property dan value.

selector {
  property: value;
}

/* Example */
p {
  color: navy;
  font-size: 16px;
}

Selector memilih elemen; property menentukan aspek yang diubah; value menentukan nilainya.

Cascade, specificity, and inheritance

Ketika beberapa aturan cocok pada elemen yang sama, browser menentukan deklarasi yang berlaku berdasarkan cascade. Specificity adalah bobot selector untuk menyelesaikan konflik.

Gambaran umum: ID selector biasanya lebih spesifik daripada class/attribute/pseudo-class; class lebih spesifik daripada type selector. Cascade juga mempertimbangkan origin, importance, dan layer.
p { color: gray; }
.note { color: royalblue; }
#warning { color: crimson; }

Jika elemen memiliki class="note" dan id="warning", deklarasi ID biasanya menang untuk properti color. Inheritance berarti beberapa properti seperti color dan font-family dapat diwariskan dari parent ke child.

CSS box model

Setiap elemen dapat dipahami sebagai kotak yang terdiri dari content, padding, border, dan margin.

Box model layers

Margin
Border
Padding
Content

Recommended reset

* { box-sizing: border-box; }
.card {
  width: 300px;
  padding: 20px;
  border: 1px solid;
}

border-box membuat width/height mencakup content, padding, dan border. Margin tetap di luar.
